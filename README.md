# E-3914 concept PWA

Arquivos prontos para publicar no GitHub Pages.

## Conteúdo
- index.html
- manifest.json
- sw.js
- icons/icon-192.png
- icons/icon-512.png

## Publicação
1. Suba todos os arquivos para o repositório.
2. Garanta que `index.html` esteja na raiz.
3. Ative o GitHub Pages em **Settings > Pages**.
4. Escolha a branch `main` e a pasta `/(root)`.
5. Aguarde a publicação.

## Botão de instalação
